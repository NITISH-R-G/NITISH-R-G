# Attributions

This profile makes use of the following open-source tools, widgets, and services to enhance its visual appeal and provide dynamic metrics:

- **[Readme Typing SVG](https://github.com/denvercoder1/readme-typing-svg)**: Used for the dynamic, animated typing effect in the header. (Hosted via `.demolab.com`).
- **[GitHub Readme Stats](https://github.com/anuraghazra/github-readme-stats)**: Used to generate the GitHub statistics and Top Languages cards.
- **[GitHub Readme Streak Stats](https://github.com/DenverCoder1/github-readme-streak-stats)**: Used to display the GitHub contribution streak card. (Hosted via `.demolab.com`).
- **[Skill Icons](https://github.com/tandpfun/skill-icons)**: Used to render the clean, unified tech stack icons in the `FOUNDER_DASHBOARD` section.
- **[GitHub Profile Trophy](https://github.com/ryo-ma/github-profile-trophy)**: Used to dynamically generate profile trophies based on GitHub activity.
- **[GitHub Profile 3D Contrib](https://github.com/yoshi389111/github-profile-3d-contrib)**: Used (via GitHub Actions) to generate the 3D contribution graph.
- **[Shields.io](https://shields.io/)**: Used to create the custom badges for project tech stacks and external links.

All widgets and tools are used in accordance with their respective open-source licenses. Thank you to the creators and maintainers of these excellent developer tools!
