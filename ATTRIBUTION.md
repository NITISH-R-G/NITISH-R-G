# ATTRIBUTIONS

The tools and widgets used in this GitHub Profile README are properly attributed to their creators and maintainers:

- **Readme Typing SVG**: Dynamically generated typing animations. Repository: [readme-typing-svg](https://github.com/DenverCoder1/readme-typing-svg) by DenverCoder1.
- **GitHub Readme Stats**: Dynamically generated GitHub stats and top languages cards. Repository: [github-readme-stats](https://github.com/anuraghazra/github-readme-stats) by Anurag Hazra.
- **GitHub Readme Streak Stats**: Dynamically generated GitHub contribution streak stats. Repository: [github-readme-streak-stats](https://github.com/DenverCoder1/github-readme-streak-stats) by DenverCoder1.
- **GitHub Profile Trophy**: Dynamically generated GitHub trophies based on user stats. Repository: [github-profile-trophy](https://github.com/ryo-ma/github-profile-trophy) by ryo-ma.
- **Skill Icons**: Beautiful skill icons for developers. Repository: [skillicons](https://github.com/tandpfun/skill-icons) by tandpfun.

Thanks to the open-source community for making these awesome tools available!
