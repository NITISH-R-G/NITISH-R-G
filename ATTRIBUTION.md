# Attributions

This profile README leverages several awesome open-source tools and services to provide dynamic content, statistics, and visual flair.

Here are the tools used:

- **[Readme Typing SVG](https://github.com/DenverCoder1/readme-typing-svg)** by DenverCoder1 - Used for the typing animation in the header.
- **[Skill Icons](https://github.com/tandpfun/skill-icons)** by tandpfun - Used for the beautiful, themeable tech stack icons.
- **[GitHub Readme Stats](https://github.com/anuraghazra/github-readme-stats)** by anuraghazra - Used to dynamically render GitHub statistics and top languages cards.
- **[GitHub Readme Streak Stats](https://github.com/DenverCoder1/github-readme-streak-stats)** by DenverCoder1 - Used to display the GitHub contribution streak card.
- **[GitHub Profile Trophy](https://github.com/ryo-ma/github-profile-trophy)** by ryo-ma - Used for displaying GitHub achievements.
- **[Shields.io](https://shields.io/)** - Used for generating static badges for projects and portfolio links.
- **[Github Profile Views Counter](https://github.com/antonkomarev/github-profile-views-counter)** by antonkomarev - Used to track and display the number of profile views.
