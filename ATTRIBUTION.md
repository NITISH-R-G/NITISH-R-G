# 📝 ATTRIBUTION

This repository uses various open-source tools, widgets, and services to create a dynamic and interactive GitHub profile.

## Widgets & Automations

- **[readme-typing-svg](https://github.com/DenverCoder1/readme-typing-svg):** Used for the animated typing effect in the header. (MIT License)
- **[github-readme-stats](https://github.com/anuraghazra/github-readme-stats):** Used to display GitHub stats and top languages cards. (MIT License)
- **[github-readme-streak-stats](https://github.com/DenverCoder1/github-readme-streak-stats):** Used to display the contribution streak stats. (MIT License)
- **[github-profile-trophy](https://github.com/ryo-ma/github-profile-trophy):** Used for adding dynamic GitHub trophies. (MIT License)
- **[skillicons.dev](https://skillicons.dev):** Used for rendering professional-looking skill icons in the tech stack section.
- **[github-profile-3d-contrib](https://github.com/yoshi389111/github-profile-3d-contrib):** GitHub action to generate 3D contribution graphs. (MIT License)
- **[github-profile-views-counter](https://github.com/antonkomarev/github-profile-views-counter):** Used for tracking profile views. (MIT License)

## Actions

- **[waka-readme](https://github.com/athul/waka-readme):** GitHub Action to update WakaTime stats.
- **[github-activity-readme](https://github.com/jamesgeorge007/github-activity-readme):** GitHub Action to fetch recent GitHub activity.
- **[blog-post-workflow](https://github.com/gautamkrishnar/blog-post-workflow):** GitHub Action to fetch the latest blog posts.

Thanks to all the creators of these fantastic tools!
