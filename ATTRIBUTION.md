# Attribution

This project uses various open-source tools, components, and widgets to dynamically enhance the GitHub Profile README.

## Widgets and Badges
- **[readme-typing-svg](https://github.com/denvercoder1/readme-typing-svg)**: Used for the typing animation header.
- **[github-readme-stats](https://github.com/anuraghazra/github-readme-stats)**: Used for dynamic GitHub stats cards.
- **[github-readme-streak-stats](https://github.com/DenverCoder1/github-readme-streak-stats)**: Used for displaying GitHub commit streaks.
- **[skillicons.dev](https://skillicons.dev)**: Used for rendering beautiful tech stack icons.
- **[github-profile-trophy](https://github.com/ryo-ma/github-profile-trophy)**: Used for showcasing GitHub profile trophies.

## Actions and Automations
- GitHub Actions used to update Activity, WakaTime metrics, and dev.to blog posts are documented in the workflow files.
- **[github-profile-3d-contrib](https://github.com/yoshi389111/github-profile-3d-contrib)**: Used to generate the 3D contribution graph.
