# Attributions

This project utilizes several open-source tools, widgets, and services to enhance the GitHub Profile README. I am grateful to the creators and maintainers of these projects.

### Dynamic Widgets & Badges
* **[GitHub Readme Stats](https://github.com/anuraghazra/github-readme-stats)**: Used for dynamically generating GitHub stats cards and top languages widgets.
* **[GitHub Readme Streak Stats](https://github.com/DenverCoder1/github-readme-streak-stats)**: Used for displaying contribution streak statistics.
* **[Readme Typing SVG](https://github.com/denvercoder1/readme-typing-svg)**: Used for the dynamic typing animation header.
* **[GitHub Profile Trophy](https://github.com/ryo-ma/github-profile-trophy)**: Used for displaying GitHub profile trophies.

### Icons & Assets
* **[Skill Icons](https://github.com/tandpfun/skill-icons)**: Used for displaying beautiful skill icons (`skillicons.dev`).
* **[Shields.io](https://shields.io/)**: Used for generating custom static badges for technologies, links, and projects.

### Automations
* **[WakaTime Readme](https://github.com/athul/waka-readme)**: Used for updating the README with WakaTime coding metrics.
* **[GitHub Profile 3D Contrib](https://github.com/yoshi389111/github-profile-3d-contrib)**: Used for generating the 3D contribution graph.
* **[GitHub Activity Readme](https://github.com/jamesgeorge007/github-activity-readme)**: Used for displaying recent GitHub activity.
* **[Blog Post Workflow](https://github.com/gautamkrishnar/blog-post-workflow)**: Used for pulling in recent Dev.to blog posts.
* **[GitHub Contribution Grid Snake](https://github.com/Platane/snk)**: Used for generating the contribution grid snake animation.
