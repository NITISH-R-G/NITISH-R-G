# 📜 ATTRIBUTION

This repository utilizes several open-source tools and widgets to enhance the profile's visual appeal and functionality. Special thanks to the creators of:

- [readme-typing-svg](https://github.com/DenverCoder1/readme-typing-svg): Dynamic typing animations for the profile header.
- [github-readme-stats](https://github.com/anuraghazra/github-readme-stats): Real-time GitHub statistics and top languages cards.
- [github-readme-streak-stats](https://github.com/DenverCoder1/github-readme-streak-stats): Displaying commit streaks.
- [github-profile-trophy](https://github.com/ryo-ma/github-profile-trophy): GitHub profile trophies dynamically generated based on stats.
- [skillicons.dev](https://github.com/tandpfun/skill-icons): Beautiful icons for the tech stack showcase.
- [shields.io](https://shields.io/): Consistent and customizable badges used throughout the project sections.
