# Attributions

This profile uses the following third-party widgets and tools:

- [readme-typing-svg](https://github.com/denvercoder1/readme-typing-svg): Used for the dynamic typing animation header.
- [skillicons.dev](https://skillicons.dev): Used for rendering professional skill badges.
- [github-readme-stats](https://github.com/anuraghazra/github-readme-stats): Used for displaying top languages and GitHub stats.
- [github-readme-streak-stats](https://github.com/DenverCoder1/github-readme-streak-stats): Used for the contribution streak widget.
- [github-profile-trophy](https://github.com/ryo-ma/github-profile-trophy): Used for the GitHub profile trophies.
- [github-profile-3d-contrib](https://github.com/yoshi389111/github-profile-3d-contrib): Used for the 3D contribution graph.
