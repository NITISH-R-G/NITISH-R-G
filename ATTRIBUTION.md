# Attributions

This project relies on several incredible open-source tools and services to dynamically power the profile dashboard. A huge thanks to the developers and maintainers of these projects:

* **[Readme Typing SVG](https://github.com/DenverCoder1/readme-typing-svg)** - Used for the dynamic typing animation in the header.
* **[GitHub Readme Stats](https://github.com/anuraghazra/github-readme-stats)** - Used for dynamically generating GitHub stats cards and top languages cards.
* **[GitHub Readme Streak Stats](https://github.com/DenverCoder1/github-readme-streak-stats)** - Used for tracking and displaying GitHub contribution streaks.
* **[GitHub Profile Trophy](https://github.com/ryo-ma/github-profile-trophy)** - Used for displaying automated GitHub achievement trophies.
* **[Skill Icons](https://github.com/tandpfun/skill-icons)** - Used to dynamically render the responsive tech stack icons.
* **[Shields.io](https://shields.io/)** - Used extensively for various badges throughout the README.
* **[Profile Counter](https://github.com/abhisheknaiidu/profile-counter)** - Used to track the number of profile views.
* **[Star History](https://star-history.com/)** - Used for the repository star tracking chart.
