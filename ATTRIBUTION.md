# Attribution

This project incorporates tools and widgets from the open-source community to enhance the visual appeal and automation of the GitHub profile.

- [readme-typing-svg](https://github.com/denvercoder1/readme-typing-svg) - Used for the dynamic animated typing text in the header.
- [github-readme-stats](https://github.com/anuraghazra/github-readme-stats) - Used for GitHub stats and top languages cards.
- [github-readme-streak-stats](https://github.com/DenverCoder1/github-readme-streak-stats) - Used to display GitHub commit streaks.
- [skillicons.dev](https://skillicons.dev/) - Used for displaying technology icons in the tech stack section.
- [github-profile-trophy](https://github.com/ryo-ma/github-profile-trophy) - Used for displaying GitHub profile trophies.
- [github-profile-views-counter](https://github.com/antonkomarev/github-profile-views-counter) - Used for tracking profile views.
- [readme-jokes](https://github.com/ABSphreak/readme-jokes) - Used for the dynamic developer jokes widget.
- [blog-post-workflow](https://github.com/gautamkrishnar/blog-post-workflow) - Used for automatically pulling latest blog posts.
- [waka-readme](https://github.com/athul/waka-readme) - Used for integrating WakaTime stats.
- [github-activity-readme](https://github.com/jamesgeorge007/github-activity-readme) - Used to display recent GitHub activity.
- [github-profile-3d-contrib](https://github.com/yoshi389111/github-profile-3d-contrib) - Used to generate 3D contribution graphs.
