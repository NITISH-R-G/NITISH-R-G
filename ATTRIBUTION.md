# Attributions

This profile was built using the following amazing tools and open-source projects:

- **[Readme Typing SVG](https://github.com/DenverCoder1/readme-typing-svg)** - Dynamic typing effect for the profile header.
- **[GitHub Readme Stats](https://github.com/anuraghazra/github-readme-stats)** - Dynamic GitHub stats and top languages cards.
- **[GitHub Readme Streak Stats](https://github.com/DenverCoder1/github-readme-streak-stats)** - Dynamic GitHub commit streak card.
- **[Skill Icons](https://skillicons.dev/)** - Beautiful icons for the tech stack showcase.
- **[GitHub Profile Trophy](https://github.com/ryo-ma/github-profile-trophy)** - Dynamic trophies based on GitHub activity.
- **[GitHub Activity Readme](https://github.com/jamesgeorge007/github-activity-readme)** - GitHub Action to append latest activity to the README.
- **[Waka Readme](https://github.com/athul/waka-readme)** - GitHub Action to display WakaTime metrics.
- **[Blog Post Workflow](https://github.com/gautamkrishnar/blog-post-workflow)** - GitHub Action to pull the latest dev.to blog posts.
- **[GitHub Profile 3D Contrib](https://github.com/yoshi389111/github-profile-3d-contrib)** - GitHub Action to generate a 3D isometric commit graph.
