# Project Attributions

This document acknowledges the third-party tools and widgets used to create this GitHub profile README.

## Widgets & Automations
* **[GitHub Readme Stats](https://github.com/anuraghazra/github-readme-stats)**: Used for dynamic GitHub stats and top languages cards.
* **[GitHub Readme Streak Stats](https://github.com/DenverCoder1/github-readme-streak-stats)**: Used for displaying continuous contribution streaks.
* **[Readme Typing SVG](https://github.com/denvercoder1/readme-typing-svg)**: Used for the animated typing header.
* **[Skill Icons](https://github.com/tandpfun/skill-icons)**: Used to display beautiful technology and tool icons.

## Workflows
* **[GitHub Profile 3D Contrib](https://github.com/yoshi389111/github-profile-3d-contrib)**: Used via GitHub Actions (`profile-3d.yml`) to generate the 3D contribution graph.
* **[Waka Readme](https://github.com/athul/waka-readme)**: Used via GitHub Actions (`waka.yml`) to display WakaTime coding metrics.
* **[Blog Post Workflow](https://github.com/gautamkrishnar/blog-post-workflow)**: Used via GitHub Actions (`blog.yml`) to fetch the latest dev.to posts.
* **[GitHub Activity Readme](https://github.com/jamesgeorge007/github-activity-readme)**: Used via GitHub Actions (`activity.yml`) to update recent GitHub activity.
