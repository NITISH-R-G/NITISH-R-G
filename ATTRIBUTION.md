# Attributions

This profile uses several open-source tools, widgets, and services to create a dynamic and interactive experience. A huge thanks to the creators and maintainers of these projects:

* **[Readme Typing SVG](https://github.com/DenverCoder1/readme-typing-svg)** - Used for the dynamic typing animation in the header.
* **[GitHub Readme Stats](https://github.com/anuraghazra/github-readme-stats)** - Used for displaying GitHub statistics and top languages cards.
* **[GitHub Readme Streak Stats](https://github.com/DenverCoder1/github-readme-streak-stats)** - Used for displaying the current GitHub contribution streak.
* **[Skill Icons](https://github.com/tandpfun/skill-icons)** - Used to beautifully showcase the tech stack.
* **[Readme Jokes](https://github.com/ABSphreak/readme-jokes)** - Used for generating random developer jokes.
* **[GitHub Profile 3D Contrib](https://github.com/yoshi389111/github-profile-3d-contrib)** - Used for generating the 3D contribution graph.
* **[Snk (Snake Animation)](https://github.com/Platane/snk)** - Used for generating the contribution grid snake animation.
* **[GitHub Profile Trophy](https://github.com/ryo-ma/github-profile-trophy)** - Used for displaying GitHub profile trophies.
