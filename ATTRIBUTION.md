# 📝 ATTRIBUTION.md

This project leverages several awesome open-source tools, widgets, and services to create a dynamic and visually appealing GitHub Profile README.

## Widgets & Automations
*   **[Readme Typing SVG](https://github.com/denvercoder1/readme-typing-svg)**: Used for the dynamic, typing headline animation. (Hosted via Demolab endpoints for stability).
*   **[GitHub Readme Stats](https://github.com/anuraghazra/github-readme-stats)**: Used for dynamically generating GitHub stats cards and top languages cards.
*   **[GitHub Readme Streak Stats](https://github.com/DenverCoder1/github-readme-streak-stats)**: Used for showcasing contribution streaks.
*   **[GitHub Profile Trophy](https://github.com/ryo-ma/github-profile-trophy)**: Used for displaying GitHub achievements as trophies.
*   **[Skill Icons](https://github.com/tandpfun/skill-icons)**: Used for rendering a clean, grid-based showcase of programming languages and tools (`skillicons.dev`).
*   **[Visitor Badge](https://visitor-badge.laobi.icu/)**: Used for displaying profile views.
*   **[Profile Counter](https://profile-counter.glitch.me)**: Another variant for visitor tracking.
*   **[Flag Counter](https://s01.flagcounter.com/)**: Used for displaying visitor origins.
*   **[GitHub Profile 3D Contrib](https://github.com/yoshi389111/github-profile-3d-contrib)**: GitHub action used for the 3D contribution graph.
*   **[Snk (Snake)](https://github.com/Platane/snk)**: GitHub action used for generating the contribution grid snake animation.
*   **[Star History](https://star-history.com/)**: Used for charting star history over time.
*   **[Count.getloli.com](https://count.getloli.com/)**: Used for tracking profile views.

## Shields & Badges
*   **[Shields.io](https://shields.io/)**: Used extensively for custom badges (tools, projects, links) with customized logos.
