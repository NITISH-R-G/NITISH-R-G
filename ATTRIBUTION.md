# Attributions

This project utilizes several open-source tools and widgets to enhance the visual appeal and functionality of the GitHub profile README.

## Tools Used

- **[readme-typing-svg](https://github.com/DenverCoder1/readme-typing-svg)**: Used for the dynamic typing animation header.
- **[github-readme-stats](https://github.com/anuraghazra/github-readme-stats)**: Used for generating the GitHub stats and Top Languages cards.
- **[github-readme-streak-stats](https://github.com/DenverCoder1/github-readme-streak-stats)**: Used for displaying the current and longest GitHub contribution streaks.
- **[skillicons.dev](https://skillicons.dev/)**: Used for displaying beautiful, dark-themed technology stack icons.
- **[github-profile-trophy](https://github.com/ryo-ma/github-profile-trophy)**: Used for displaying GitHub profile trophies based on contribution metrics.
- **[komarev/ghpvc](https://github.com/komarev/ghpvc)**: Used for the dynamic profile view counter.

Many thanks to the creators and maintainers of these fantastic tools!
