# Attributions & Tools Used

This profile README utilizes several open-source tools and widgets to enhance its visual appeal and provide dynamic functionality. A big thank you to the creators of these fantastic projects!

- **Readme Typing SVG** by [DenverCoder1](https://github.com/DenverCoder1/readme-typing-svg)
  - Used for the dynamic, typing headline animation at the top of the profile.

- **GitHub Readme Stats** by [anuraghazra](https://github.com/anuraghazra/github-readme-stats)
  - Used for generating the GitHub stats cards and top languages widgets.

- **GitHub Readme Streak Stats** by [DenverCoder1](https://github.com/DenverCoder1/github-readme-streak-stats)
  - Used for tracking and displaying GitHub contribution streaks.

- **Skill Icons** by [tandpfun](https://github.com/tandpfun/skill-icons)
  - Used to dynamically render the grid of technology and tool icons.

- **GitHub Profile Views Counter** by [antonkomarev](https://github.com/antonkomarev/github-profile-views-counter)
  - Used to track the number of visits to this profile.

- **GitHub Profile 3D Contrib** by [yoshi389111](https://github.com/yoshi389111/github-profile-3d-contrib)
  - Used via GitHub Actions to automatically generate a 3D commit graph.
