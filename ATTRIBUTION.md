# Attributions

This profile leverages several open-source tools and services to create a dynamic and engaging experience.

*   **readme-typing-svg**: Used for the typing animation in the header.
*   **github-readme-stats**: Used for the GitHub statistics and top languages cards.
*   **github-readme-streak-stats**: Used for the GitHub contribution streak card.
*   **skillicons.dev**: Used for the tech stack icons.
*   **shields.io**: Used for various badges throughout the profile.
