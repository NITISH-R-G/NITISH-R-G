# Attributions

This repository uses several amazing open-source widgets and badges to enhance the profile README.

We would like to sincerely thank the creators and maintainers of the following projects:

- **[readme-typing-svg](https://github.com/DenverCoder1/readme-typing-svg)** by DenverCoder1 - Used for the dynamic typing animation in the `SYSTEM_STATUS` section.
- **[skillicons.dev](https://github.com/tandpfun/skill-icons)** by tandpfun - Used for the beautifully designed technology stack icons in the `NEURAL_ARCHITECTURE` section.
- **[github-readme-streak-stats](https://github.com/DenverCoder1/github-readme-streak-stats)** by DenverCoder1 - Used to showcase GitHub contribution streaks.

*Note: The widgets are used dynamically, and all rendering is handled either via open APIs provided by the respective services or via local GitHub Actions.*
