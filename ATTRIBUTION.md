# Attributions

This repository uses several third-party open-source tools, services, and assets to generate dynamic widgets and visual badges. Credit goes to their respective creators:

- **[readme-typing-svg](https://github.com/DenverCoder1/readme-typing-svg)**: Used for the dynamic typing animation header.
- **[github-readme-stats](https://github.com/anuraghazra/github-readme-stats)**: Used for dynamic GitHub profile statistics and top languages cards.
- **[github-readme-streak-stats](https://github.com/DenverCoder1/github-readme-streak-stats)**: Used for displaying GitHub contribution streak statistics.
- **[skillicons.dev](https://skillicons.dev/)**: Used for rendering the technology stack icons.
- **[github-profile-trophy](https://github.com/ryo-ma/github-profile-trophy)**: Used for displaying profile trophies based on GitHub metrics.
- **[profile-counter](https://github.com/journey-ad/profile-counter)**: Used for tracking profile views.
- **[Shields.io](https://shields.io/)**: Used for rendering static badges for projects and technologies.
